14 """Performs interpolation of image data onto the FEM Discretization based 

15 on the specified calculation type. 

16 

17 This function applies different interpolation methods depending on the 

18 user configuration. The pixel values are assigned to the FEM elements 

19 using one of the following approaches: 

20 

21 - "nodes": Computes the mean pixel value for each element based on its 

22 node values. 

23 - "allvoxels": Computes the mean pixel value for each element based on 

24 all voxels inside it. 

25 - "elementcenter": Assigns pixel values based on the center of each 

26 element. 

27 

28 Arguments: 

29 dis (Discretization): The Discretization object containing FEM 

30 elements and node coordinates. 

31 image_data (ImageData): A structured representation containing 3D 

32 pixel data, grid coordinates, orientation, and metadata. 

33 interpolation_method (str): The type of interpolation to perform for 

34 assigning pixel values to the elements. This should match one of 

35 the `InterpolationType` enum values (e.g., "nodes", 

36 "elementcenter", "allvoxels"). 

37 

38 Returns: 

39 list[Element]: A list of FEM elements with interpolated pixel data. 

40 """ 

41 

42 enum_interpolation_method = InterpolationType(interpolation_method) 

43 

44 interpolator = enum_interpolation_method.get_interpolator()() 

45 

46 return interpolator.compute_element_data(dis, image_data)
